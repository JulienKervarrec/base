# Limites et verification

Ce monorepo evolue avec les mises a niveau Base et OP Stack ; les parametres reseau priment sur un guide statique.
La compatibilite EVM ne supprime ni risque de sequencer ni dependance aux contrats L1.
Les niveaux unsafe, safe et finalized doivent etre exposes aux applications sensibles.
Les retraits exigent une preuve valide, la maturite du jeu de contestation et une execution L1 distincte.
Ce parcours repose sur le README, les configurations, composants node et contrats de pont presents dans le depot.
Aucune installation, compilation, synchronisation de noeud ou execution nouvelle n a ete effectuee.
Aucun statut de test ou de reseau n est revendique ici.
Pour verifier, consulter les suites de tests et la documentation operateur correspondant a la version deployee.
