# Retraits et fault proofs

Un retrait commence sur L2 puis son message est prouve et finalement execute sur Ethereum.
La proposition d output engage l etat L2 utilise pour construire la preuve de retrait.
Les fault proofs permettent de contester un engagement incorrect via un dispute game.
La periode de contestation separe l initiation de la finalisation et protege le pont canonique.
Le portail L1 verifie preuve, maturite et absence de rejeu avant l execution finale.
Les retraits ne doivent pas etre annonces finalises sur la seule foi d une inclusion unsafe.
Les outils d exploitation doivent surveiller dispute games, outputs et versions de contrats.
