## Modele de confiance TEE dans Base

Ce chapitre presente le mecanisme et ses frontieres a partir des fichiers du depot. Il distingue les donnees d entree, les controles applicatifs, les evenements et les erreurs possibles. Une integration robuste doit conserver les identifiants necessaires, verifier les preconditions et traiter les reprises sans supposer qu une transaction reussie suffit a prouver l etat final. Les exemples servent a la lecture du code et ne constituent ni un audit ni un resultat de test.
