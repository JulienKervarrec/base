## Glossaire technique Base

Ce chapitre complete le parcours francais de Base par une lecture ciblee du mecanisme. Il decrit les entrees, les etats intermediaires, les controles et les signaux observables. La documentation separe les garanties du protocole des responsabilites de l integration. Elle signale les erreurs, les reprises et les limites de ce qui peut etre deduit d un evenement. Cette note repose sur la lecture statique des sources et ne declare aucun test execute.
